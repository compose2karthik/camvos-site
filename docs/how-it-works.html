HOW IT WORKS

From setup to the last guest.
A clearer way to run the event.

A six-stage walkthrough of the intended operator journey. Illustrated workflows depend on the selected release and supported hardware.

Create. Capture. Deliver.

01

Create Your Event

Enter the event information and prepare the working setup.

02

Add Experiences

Choose the photo, motion or creative Experiences appropriate for the event.

03

Design the Result

Create or reuse Layouts, branding and output settings for each Experience.

04

Connect Your Hardware

Select supported cameras, printers and displays. Actionable guidance should identify missing capabilities.

05

Go Live

Launch ready Experiences and guide guests through capture.

06

Create & Deliver

Produce the selected result and use the configured printing, local gallery or supported delivery channel.

Keep the event moving.

Local capture is designed to work independently of venue Wi-Fi. Cloud AI and connected delivery may require internet. Recovery should preserve completed work and make the next action clear; this behavior requires release-specific validation.
